# 🔐 Firebase Login Page

A simple, minimalist user authentication interface built with **HTML**, **CSS**, and **JavaScript**, using **Firebase Authentication** for user sign-up and login functionality.

---

## 📌 Features

- ✅ User Registration with Email & Password  
- ✅ User Login with Firebase Authentication  
- ✅ Clean, professional UI inspired by Google's Material Design  
- ✅ Typed.js dynamic text greeting on main page  
- ✅ Modern responsive layout with Poppins font

---

## 🚀 Technologies Used

- HTML5 / CSS3  
- Vanilla JavaScript  
- Firebase Authentication  
- Typed.js for dynamic messages  
- Google Fonts (Poppins)

---

## 🗂️ File Structure

/project-folder
    │
    /public
        ├── index.html # Default entry point
        ├── login.html # Login page (redirected on load)
        ├── main.html # Welcome page after successful login
        ├── style.css # Clean modern styling
        ├── firebaseauth.js # Handles login & sign-up logic
        ├── main.js # Displays dynamic greeting with username
        └── README.md # You're reading it now

---

## 🔧 Setup Instructions

1. Clone or download this repository.
2. Replace the Firebase config in `firebaseauth.js` with your own Firebase project credentials.
3. Host it locally or on a static site host (e.g. GitHub Pages, Firebase Hosting).
4. Open `index.html` — it will automatically redirect to `login.html`.
